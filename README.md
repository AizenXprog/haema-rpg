# HÆMA — Arquivo Vivo

Portal inicial do sistema autoral de RPG HÆMA (Haematomânthía).

## Abrir localmente
Abra `index.html` em um navegador moderno. Não exige instalação ou build.

## Publicar
Crie um repositório GitHub para este projeto, envie `index.html`, `style.css` e `script.js` para a branch `main` e importe esse repositório na Vercel, com Framework Preset: **Other** e Output Directory vazia.

## Conteúdo
Apresentação editorial e navegável, ficha demonstrativa de cinco atributos (armazena dados somente neste navegador), rolagem de 2d10 e regras introdutórias consistentes com o Manual de Jogo v1.0.

## Atenção editorial
Este site é uma **primeira versão de apresentação**, não substitui o manual completo nem a ficha digital completa. Metus e a cosmologia estão em desenvolvimento. O título editorial "Volume I / O despertar" é apenas um elemento de interface, não lore oficial.

## Acessibilidade
Contém navegação por teclado, textos adaptáveis, estados de botões e redução de movimentos para dispositivos que solicitam menos animação.
